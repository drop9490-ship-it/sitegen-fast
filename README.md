A faster drop-in for makefun-site 1.0.0: `solve.js` returns byte-for-byte the same output tree, about three times faster on the practice set. Fused single-pass Markdown, templates compiled to JS functions with page-independent fragments memoised per case, cached slugs, bulk escaping. No dependencies, no WASM, no native code.

## Run it

```sh
node main.ts
```
